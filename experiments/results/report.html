Key finding: Across all 3 complete tasks, the more token-efficient model changes depending on the context tier. However, because these observations come from single runs without replication, these reversals reflect a combination of true interaction effects and run-to-run stochasticity.

Methods and limitations

  • Repository: contextroute-shop · Fixture commit: 6a04966b04f2bee261f11fbb203cd2bef3d9769c
  • Models: Big Pickle and DeepSeek V4.1 Flash Free (OpenCode-hosted). Gemini 3.5 Flash Lite excluded (no API key).
  • OpenCode v2.2.7 in standalone/archived/auto mode. Shell, subagent, external_directory access denied.
  • Context tiers C1/C2/C3 built by the existing BM25-deps-v2 retrieval engine.
  • Tokens: provider-reported cumulative session totals (input + output). OpenCode-hosted models report $0 cost.
  • With 3 complete tasks, leave-one-out folds have only 2 training tasks — below the minimum of 4 for empirical joint routing.
  • Single execution per arm. Ranking reversals cannot be distinguished from run-to-run noise without replication.
  • One synthetic repository and task set. Results may not generalize.
